# 情绪地图与表达控制

文学参照不是情绪全集，也不是决定情绪的起点。写作中的情绪不应被压缩成“悲伤、愤怒、希望”三个按钮。真正清楚的情绪，通常由事件、解释、欲望、身体反应、行动冲动和现实限度共同组成；同一个人还可能同时拥有几种互相拉扯的情绪。

本文件服务于写作判断，不是心理诊断量表。文学人物和作品也不是单一性格标签：下面只提取某些作品中可观察的表达机制，不声称穷尽作者本人。

## 先拆情绪

写作前用这一张情绪卡，而不是先问“像哪位名人”：

`触发事实 → 作者如何解释 → 真正想要什么 → 身体或行为反应 → 想做什么 → 什么阻止了它 → 最后留下什么`

再从以下维度定位它：

| 维度 | 两端或选项 | 对清晰度的作用 |
|---|---|---|
| 愉悦度 | 痛苦 ←→ 愉悦 | 区分受伤、平静、兴奋和满足，不把所有正面情绪写成“开心” |
| 激活度 | 低声、迟缓 ←→ 紧绷、爆发 | 决定句子速度、段落长度和动词力度 |
| 控制感 | 无法改变 ←→ 能够行动 | 区分无力、疲惫、焦虑、愤怒和决心 |
| 时间方向 | 回到过去、停在现在、投向未来 | 区分怀旧、遗憾、空虚、期待和预感 |
| 指向 | 对自己、对某个人、对群体、对世界、对命运 | 防止只写“我很难受”而不写情绪在指向谁 |
| 可见度 | 隐忍、绕行、半说半停 ←→ 直说、控诉、宣言 | 决定是用细节暗示还是用判断命名 |
| 行动冲动 | 靠近、逃离、攻击、修复、等待、纪念、放弃、创造 | 让情绪推动文本，而不是只装饰文本 |

一段文字不必把所有维度写出来，但至少要让读者辨认出情绪对象、触发事实、行动冲动或现实阻力中的几项。

## 情绪词谱

### 接近、向往与依恋

| 情绪 | 它在乎什么 | 写作时要写清 |
|---|---|---|
| 欲望 | 想得到某人、某物或某种生活 | 想要的对象和代价，不要只写“渴望美好” |
| 思念 | 缺席的人或地方仍持续占据当下 | 哪个细节被留下，缺席如何进入日常 |
| 眷恋 | 明知不完美仍不愿放手 | 留恋的是人、时间、身份，还是一种可能 |
| 温柔 | 愿意降低自己的速度和力量去照料 | 谁在照料谁，具体做了什么 |
| 亲密 | 防备降低，愿意让对方看见真实部分 | 哪个秘密、脆弱或小习惯被交出来 |
| 依赖 | 把稳定感、判断或自我价值部分交给别人 | 依赖带来安稳还是失衡 |
| 信任 | 愿意在无法完全确定时交出一部分控制 | 冒了什么风险，为什么仍然交付 |
| 感激 | 认识到自己受过他人的帮助或善意 | 帮助具体改变了什么，不要只写“铭记于心” |
| 敬意 | 被他人的人格、技艺或承担所触动 | 尊重的是哪一种选择或代价 |

### 快乐、舒展与开放

| 情绪 | 与相邻情绪的区别 | 写作抓手 |
|---|---|---|
| 欣喜 | 对已经发生的好事产生即时反应 | 表情、声音、动作或想立刻告诉谁 |
| 安心 | 预期中的危险暂时解除 | 身体终于放松在哪里 |
| 释然 | 接受某个解释或结果后停止反复争辩 | 放下的是哪一个执念，不能泛写“看开了” |
| 满足 | 现有状态已经足够，不急着扩大 | 一个刚好够用的场景或日常动作 |
| 轻快 | 暂时摆脱负担，行动变得有弹性 | 语言可以更跳跃，但仍要有具体原因 |
| 玩心 | 对世界保持试探、调皮和创造性 | 不把幽默写成逃避或强行卖萌 |
| 惊奇 | 熟悉的秩序突然打开新的可能 | 哪个细节改变了原来的认知 |
| 敬畏 | 面对比自己更大、更久或更复杂的事物 | 保留人的尺度，避免空泛宏大 |
| 庆幸 | 意识到坏结果本来可能发生，但这次躲过了 | “差一点”是什么，不能只写幸运 |

### 失去、下沉与时间

| 情绪 | 它不是 | 写作抓手 |
|---|---|---|
| 悲伤 | 不等于所有低落 | 失去的对象和当下反复回返的细节 |
| 哀痛 | 比悲伤更有持续性，常与不可逆失去相连 | 缺席者留下的空位、仪式或身体记忆 |
| 哀悼 | 对失去进行承认、纪念和重新安排生活 | 人如何处理遗物、称呼、日期和关系 |
| 孤独 | 不只是一个人，而是无人真正抵达自己的处境 | 想说却没有对象，或有人在场却无法连接 |
| 空虚 | 不是单纯疲劳，而是目标和意义暂时失去回声 | 做了什么却感觉没有抵达哪里 |
| 怀旧 | 过去被重新染上情感，不必等于想回去 | 记忆中的气味、物件与现实的差距 |
| 遗憾 | 对已经发生且无法完全修复的选择回望 | 当时不知道什么，现在明白了什么 |
| 后悔 | 认为自己本可采取不同行动，并愿意承担责任 | “如果重来”具体改变哪一步 |
| 倦怠 | 长期消耗让感受和行动力变薄 | 消耗来自哪里，休息能否真正解决 |
| 麻木 | 感受被压低或隔开，不等于平静 | 哪些事情本该有反应却没有，代价是什么 |

### 恐惧、焦虑与不确定

| 情绪 | 核心问题 | 写作抓手 |
|---|---|---|
| 害怕 | 眼前或预期的危险可能伤害自己 | 危险是什么、距离多近、身体如何反应 |
| 焦虑 | 结果尚未发生，却不断预演失控 | 反复检查、等待、假设和无法停下的思绪 |
| 忧惧 | 对重要而持久的风险有沉重预感 | 它牵涉谁，为什么不能简单躲开 |
| 惊恐 | 危险感骤然压过思考能力 | 呼吸、空间、声音和动作的急促变化 |
| 戒备 | 不相信危险已经过去，持续扫描信号 | 哪个细节让人无法放松，是否有误判可能 |
| 猜疑 | 证据不够，却无法停止解释他人的动机 | 事实、推测和投射要分开 |
| 不安 | 没有明确危险，但秩序感觉出了偏差 | 哪个小地方不对，不能直接宣布“预感成真” |
| 羞怯 | 想靠近又害怕暴露自己 | 说到哪一句停住，身体如何退后 |
| 预感 | 对未来的方向有模糊感觉 | 只写感觉的来源，不把它伪装成事实 |

### 愤怒、抵抗与破坏冲动

| 情绪 | 与相邻情绪的区别 | 写作抓手 |
|---|---|---|
| 挫败 | 想做的事被阻碍，能量还在 | 障碍是什么，下一步能否调整策略 |
| 恼怒 | 眼前刺激令人不快，通常持续较短 | 不要夸大成道德审判 |
| 愤怒 | 认为伤害不该发生，要求改变或责任 | 谁做了什么，谁承担后果 |
| 义愤 | 愤怒超出个人得失，指向不公 | 先给受损者和事实，再给价值判断 |
| 怨恨 | 伤害反复回放，情绪与对象长期绑定 | 恨的是事件、失去的尊严，还是未获道歉 |
| 憋屈 | 有话、有理或有力气，却被处境压住不能说做 | 谁拥有话语权，沉默付出什么代价 |
| 轻蔑 | 把对象判断为不值得尊重 | 让判断由行为推出，避免作者居高临下 |
| 厌恶 | 身体或价值层面对某物强烈排斥 | 是气味、行为、制度还是自我某部分 |
| 反抗 | 不接受既有安排，并准备承担代价 | 反抗对象、边界和实际动作 |
| 报复 | 希望对方承受与自己相近的伤害 | 说明欲望和代价，不把伤害浪漫化 |
| 嘲讽 | 用距离和反差暴露荒谬或自我保护 | 笑点背后真正不能承受的是什么 |

### 自我、道德与尊严

| 情绪 | 核心差异 | 写作抓手 |
|---|---|---|
| 尴尬 | 社交秩序短暂失误，通常可以恢复 | 现场的目光、停顿和补救动作 |
| 羞耻 | 感觉“是我这个人不值得被看见” | 不要把人物的自我判断当成客观事实 |
| 内疚 | 认为自己的行为伤害了别人或违反了责任 | 具体做错了什么，能否修复 |
| 悔恨 | 对失去的机会或造成的伤害进行更深的回望 | 责任、不可逆性和迟来的理解 |
| 屈辱 | 尊严被他人或制度主动压低 | 谁施加了权力，人物如何保存自我 |
| 自豪 | 认可自己或所属群体完成了有价值的事 | 成就和代价都写出来，避免空喊 |
| 尊严 | 即使处于弱势仍拒绝被完全定义或支配 | 一个拒绝、坚持或日常动作 |
| 自责 | 把复杂结果过度归因于自己 | 区分真正责任与无法控制的部分 |
| 原谅 | 不再让伤害继续决定自己的行动，不等于否认伤害 | 是否需要道歉、距离或边界 |
| 宽恕 | 对他人保留人的复杂性，同时不取消责任 | 不用“他也不容易”抹平受害者经验 |

### 关系、分离与混合

| 混合状态 | 内部拉扯 | 写作时保留什么 |
|---|---|---|
| 爱而不得 | 接近欲望与现实拒绝并存 | 爱的具体证据和不能强求的边界 |
| 又爱又恨 | 依恋、受伤、愤怒和习惯互相纠缠 | 同一对象身上相反的事实，不要替人物选边 |
| 嫉妒 | 害怕重要关系被第三者或比较夺走 | 害怕失去的是人、位置还是自我价值 |
| 羡慕 | 希望拥有他人的资源、能力或生活 | 欲望可以转化为行动，也可以腐蚀自尊 |
| 占有 | 需要把关系固定在自己可控制的范围 | 爱与控制的边界，不能包装成深情 |
| 依恋与窒息 | 需要靠近，同时害怕失去自我空间 | 靠近带来什么，退后又失去什么 |
| 信任破裂 | 事实改变了对关系未来的预期 | 不是一句“我不信了”，而是哪条经验断掉 |
| 疏离 | 曾经有连接，如今彼此仍在却无法抵达 | 变化发生在哪个时刻或习惯里 |
| 悲悯 | 看见他人的痛苦并愿意靠近，但不替他人占有声音 | 具体处境、尊重和可做的行动 |
| 同情疲劳 | 长期面对痛苦后，感受能力被消耗 | 既写受助者，也写施助者的限度 |

### 认知与存在

| 状态 | 它在文本中的作用 | 写作抓手 |
|---|---|---|
| 困惑 | 事实或意义暂时无法拼合 | 写出缺失的那一块，不急于给答案 |
| 怀疑 | 对已有解释或对象的可信度动摇 | 哪条证据不够，怀疑会带来什么代价 |
| 矛盾 | 两个都真实的愿望无法同时满足 | 让两个愿望都拥有证据，不要把一个写成借口 |
| 失望 | 现实低于原先的期待 | 期待原来有多具体，落差如何发生 |
| 幻灭 | 原先相信的整套解释崩塌 | 崩塌的不只是结果，还有自我认识或价值观 |
| 荒诞感 | 世界运行却不提供可接受的意义 | 让荒诞由事件和反差呈现，不先喊“荒诞” |
| 异化 | 人与自己的劳动、身体、群体或生活失去联系 | 哪个熟悉动作变得像在替别人完成 |
| 清醒 | 看见希望与限度，不再靠幻想维持秩序 | 清醒带来的代价和仍保留的选择 |
| 接受 | 停止要求现实变成另一种样子 | 接受不等于赞同、原谅或不再疼痛 |
| 认命 | 放弃继续争辩某个结果，可能清醒也可能麻木 | 用行动细节判断是哪一种 |
| 好奇 | 对未知保持靠近冲动 | 具体想知道什么，探索会改变什么 |
| 想象 | 用未发生的可能扩展现实 | 区分想象、愿望和事实 |

## 相近情绪的辨析

改稿时，优先处理这些容易被混用的词：

- **思念、怀旧、遗憾**：思念指向仍在心中的人或地方；怀旧把过去重新带入现在；遗憾强调“本可以不同”却没有发生。
- **悲伤、哀痛、空虚**：悲伤是对失去或受伤的反应；哀痛更持续、更不可逆；空虚是目标或意义失去回声，不一定有明确失去对象。
- **疲惫、无力、绝望**：疲惫可能通过休息恢复；无力感强调控制不了决定性结果；绝望连“仍有出口”的信念也被压低。
- **害怕、焦虑、忧惧、惊恐**：害怕有相对明确的危险；焦虑反复预演未发生的结果；忧惧更持久沉重；惊恐是瞬间压过思考能力的高激活状态。
- **挫败、愤怒、怨恨**：挫败是目标受阻；愤怒要求改变或负责；怨恨让旧伤持续占据关系和记忆。
- **尴尬、羞耻、屈辱**：尴尬是场面失序；羞耻把问题归到自我价值；屈辱通常包含他人或制度施加的权力压低。
- **内疚、自责、悔恨**：内疚针对具体伤害；自责可能过度承担不可控结果；悔恨回望不可逆的选择和迟来的理解。
- **同情、悲悯、怜悯**：同情是感到对方的痛；悲悯包含对处境和尊严的理解；怜悯若写不好容易把对方放在低处，需谨慎。
- **嫉妒、羡慕、占有**：嫉妒害怕关系被夺走；羡慕想拥有别人拥有的东西；占有试图把关系固定为自己的控制范围。
- **平静、释然、麻木、认命**：平静仍有感受；释然停止与某个解释争辩；麻木感受被隔开；认命停止争夺结果，原因可能是清醒也可能是耗尽。
- **希望、期待、幻想**：希望承认困难仍相信存在行动路径；期待把未来结果当作较具体的可能；幻想可能暂时脱离证据。不要用“希望”给所有文章打亮色滤镜。

## 混合情绪不是错误

复杂文本常常由两条或三条情绪线组成。可用“主情绪 + 伴随情绪 + 矛盾点”记录：

- **悲伤 + 庆幸**：离开的人终于不再受苦，留下的人仍然失去他。
- **愤怒 + 羞耻**：被伤害后生气，却因为自己曾经相信而责怪自己。
- **爱 + 戒备**：愿意靠近，但身体记得过去的背叛。
- **希望 + 恐惧**：看见可能性，也知道失败会再次造成损失。
- **平静 + 空虚**：争吵停止了，关系却没有回来。
- **自豪 + 内疚**：取得成就的同时，意识到有人为此承担了代价。
- **幽默 + 悲痛**：笑话不是消除痛苦，而是让人能够暂时触碰它。
- **清醒 + 眷恋**：知道应该离开，仍然会在某个时间想起对方。

混合情绪的写法不是把两个形容词并排，而是让两种情绪分别拥有事实、动作或内心判断。最少保留一处矛盾证据，读者才会相信它们同时存在。

## 情绪运动路径

可把情绪写成变化，而不是静态标签：

| 路径 | 常见过程 | 适合的收束 |
|---|---|---|
| 靠近 | 好奇 → 欣喜 → 信任 → 依恋 | 交付、承诺、日常照料 |
| 追逐 | 欲望 → 期待 → 焦虑 → 挫败 | 调整目标、继续试、退出 |
| 失去 | 震惊 → 否认/麻木 → 哀痛 → 纪念或重排生活 | 留下一个空位或生活动作 |
| 背叛 | 信任 → 疑心 → 愤怒 → 悲伤/边界 | 道歉、修复、离开或不再解释 |
| 受辱 | 暴露 → 羞耻/屈辱 → 自责或反抗 → 尊严重建 | 一个拒绝、证词或选择 |
| 消耗 | 责任 → 忍耐 → 倦怠 → 麻木/重新分担 | 承认限度，而不是突然振作 |
| 追问 | 困惑 → 怀疑 → 幻灭 → 清醒/荒诞感 | 保留问题，或选择仍要做的事 |
| 见证 | 个体遭遇 → 具体悲悯 → 责任/义愤 → 行动或无法行动 | 公共判断与个人代价并存 |
| 出发 | 失意 → 自我肯定 → 冒险 → 突围或新问题 | 出发动作，不保证胜利 |
| 和解 | 对抗 → 理解 → 接受 → 边界或宽恕 | 不抹去旧伤，改变相处方式 |

路径不是固定剧本。真实文字可以停在任何一个阶段，尤其是哀痛、无力、怀疑和未完成的和解。

## 将情绪落到文本

当用户说“更有情绪”“加重一点”或“不要太悲伤”时：

1. 先从材料识别主情绪、伴随情绪和矛盾情绪，不从词表或作者名单反推情绪。
2. 写一行控制 brief：`主情绪 / 对象 / 触发事实 / 行动冲动 / 现实限度 / 强度 1-5 / 结尾余波`。
3. 选择一个变化动作：增加具体细节、拉开叙述距离、改变句子节奏、补出行动，或保留未解决的余波。
4. 写完后检查：情绪是否改变了人物的判断或行动？如果只是增加形容词、反问或感叹号，退回事实和动作。
5. 需要文学性的组织方式时，再读取 [literary-reference.md](literary-reference.md)，并且只取一到两个高层特征。

## 不应强行补上的情绪

- 失去之后不一定要希望，成功之后也不一定要欢欣。
- 沉默不一定是冷漠，笑也不一定表示轻松。
- 离开不一定是成长，留下不一定是软弱。
- 同情不一定是理解，原谅不一定是和好，接受不一定是赞同。
- 无力不一定是绝望，清醒不一定带来行动，行动也不保证结果。

当素材不足以判断情绪时，使用“可能、像是、我还不能确定”或向用户索取一个具体场景。不要用文学名人的标签替作者决定他应该感到什么。
