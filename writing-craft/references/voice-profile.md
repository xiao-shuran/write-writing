# 作者声音画像

作者声音不是几句“更有文采”或“像某位作家”。它是一个人在特定场景里反复做出的表达选择：看什么、不看什么；句子在哪儿停；对读者靠多近；愿意把哪种情绪说出来，又把哪种情绪藏在动作里。

只从用户明确提供或确认可使用、并且当前确实可读的样稿建立画像。不要根据名字、职业、年龄、地域、平台身份、文件名、附件摘要或对某位作者的偏好臆测声音；不要把用户说“像某某”直接转成可识别的模仿。

## 何时建立画像

以下情况建议先建画像：

- 用户希望长期维持自己的文风，或提供了两篇以上样稿。
- 要改写重要的第一人称文本、演讲、个人品牌内容、叙事散文或信件。
- 用户明确要求“有我的人味”“别像 AI 写的”。

单句润色、事实性公告、格式化邮件和紧急改稿通常不需要单独建画像。只要保守修订原文即可。

用户提到样稿但当前无法读取时，不建立画像，也不假装参考了它。说明缺少的样稿，要求重新附上、粘贴代表片段，或按当前原文做保守修订。完整的资料缺失处理见 [input-materials.md](input-materials.md)。

## 采样与边界

- 优先选择同一读者、同一媒介或相近用途的样稿；不同场景的写法可以不同，不要把聊天语气强加到正式文章。
- 样稿不需要很多。少量、代表性强的片段比大量风格混杂的文本更有价值。
- 记录哪些特征是直接观察到的，哪些只是暂定判断。证据不足时写“未确认”，不要补造人格或经历。
- 样稿中的事实、私人信息和引用只用于当前写作任务；除非用户要求，不复述、不扩写、不转移到其他任务。

## 声音画像卡

先给用户一个可确认的简版画像。只填写有证据的栏目：

```text
声音画像（基于用户提供样稿）
- 读者距离：亲近 / 平视 / 克制 / 正式；证据：……
- 句子与节奏：短句、长短交替、解释密度、停顿位置；证据：……
- 词汇与语气：口语度、抽象度、幽默、锋利度、礼貌程度；证据：……
- 观察习惯：偏好写动作、物件、关系、判断、数据或感受；证据：……
- 结构习惯：先场景/先结论/先提问，转折和结尾方式；证据：……
- 情绪可见度：直说、克制、绕行、反讽，或混合；证据：……
- 应避免：用户不喜欢或样稿中没有支持的表达；证据：……
- 置信度：高 / 中 / 低；未确认：……
```

用户确认前，把它视为可修改的工作假设。用户说“这不像我”时，优先请其指出哪一句或哪个特征不对，并更新画像，而不是和用户争论。

## 使用画像改写

1. 先确定任务场景和修订范围。声音画像不能覆盖场景要求，例如法律通知、工作邮件和朋友圈文字可以使用不同语域。
2. 保留用户的观点、事实、人称和真正的犹豫。声音不是装饰，而是取舍。
3. 只激活两到四项最相关的特征。全量套用会变成风格表演。
4. 对比原文与改写稿：改写是否更符合画像，同时仍更清楚、更适合当前读者？
5. 交付时最多说明三条有实质影响的声音调整，不要让用户阅读一份风格分析报告。

## 与文学参照的关系

用户自己的声音优先于任何文学参照。文学参照只能帮助选择情绪的组织方式、叙述距离或收束方式，不能覆盖用户已经建立的表达习惯。若两者冲突，保留用户声音，并说明参照只作为结构提示。

## 失败信号

- 改写后每一段都变成同一种短句或同一种“高级”腔调。
- 只留下通用的温柔、克制、深刻，却没有用户自己的判断和细节。
- 用户原本的犹豫、幽默、粗粝或不确定性被全部磨平。
- 为了“像人”而加入原稿没有的童年、关系、职业经历或口头禅。

出现上述任一信号时，退回保守修订，重新查看样稿中的具体证据。
