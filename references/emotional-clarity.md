# 情绪清晰度与无力感

情绪重不等于情绪清楚。清晰的情绪不是给段落贴上“悲伤”“治愈”或“绝望”的标签，而是让读者看见：什么事情发生了，作者想要什么，现实在哪个位置拒绝了这个愿望，作者如何理解这道裂缝，以及还剩下什么姿态。

“无力感”只是一个重点案例，不是情绪清单。情绪也可以轻盈、明亮、庸常、暧昧、矛盾、身体化、社会化或暂时难以命名；应从材料中识别情绪，而不是把所有复杂感受压成悲伤、愤怒和希望三个词。需要更宽的词汇和参照范围时，读取 [emotion-atlas.md](emotion-atlas.md)。

## 六格情绪模型

写作或改写情绪段落前，先在脑中完成这六格。成稿不必逐项明说，但至少要让其中三到四格可被读者辨认。

| 维度 | 要回答的问题 | 常见落点 |
|---|---|---|
| 事实 | 具体发生了什么？ | 一个日期、动作、物件、身体反应、现场或结果 |
| 欲望 | 人真正想要什么？ | 被理解、挽回、改变、留下、证明、告别、休息 |
| 阻力 | 什么挡住了它？ | 他人的选择、制度、身体、时间、死亡、不可逆的损失 |
| 限度 | 哪一部分无法靠努力解决？ | 不能强迫别人爱你，不能让逝者回来，不能回到原来的身体或时间 |
| 姿态 | 在这个限度里仍采取什么态度或行动？ | 继续照料、记录、拒绝、等待、道歉、保持沉默、做一件小事 |
| 余波 | 什么仍然没有被解决？ | 疼痛、怀疑、想念、羞惭、遗憾，或暂时无法命名的空缺 |

如果只有“我很难过”和“我会变好”，中间的事实、限度和姿态都缺席，文本就会显得像情绪模板。先补结构，再决定是否提高语气。

## 区分相近情绪

不要把所有低落都写成同一种黑色。可以用下面的区别校准：

- **愤怒**：认为某种伤害不该发生，并且仍在要求责任、解释或改变。
- **悲伤**：失去已经发生，注意力反复回到缺席的人、物或过去。
- **无力感**：看得见问题，也可能在乎甚至尝试过，但决定性结果不在自己控制范围内。
- **疲惫**：能力暂时被消耗，休息或分担可能恢复行动力；不必写成命运判断。
- **认命**：停止与某个结果争辩；可能是清醒的接受，也可能是麻木，要由细节判断。
- **绝望**：不仅结果不可控，连未来存在可行出口的信念也被压低；不要轻易用它形容普通挫折。
- **悲悯**：从个人痛苦看见他人的处境，但不等于替他人发言或把苦难美化。

一个人可以同时愤怒又无力、悲伤又清醒。不要为了“情绪纯度”抹掉这种矛盾；要说明哪一种情绪在这一段里承担主要动作。

## 无力感：限度中的清醒

无力感不是“什么都不做”，也不是把痛苦包装成励志。它是一种清醒处境：身体、命运、失去、时间、权力或死亡设下了无法谈判的边界；人仍能感受、思考、照料和选择，却不能因此获得对结果的控制。

写作时先承认事实的重量，再写清不能改变的究竟是什么。剩余行动可以很小，例如照料、记录、赴约、把东西放回原处；小不等于虚假。痛苦不必在最后一段被治愈，清晰也不要求圆满。

不要把无力感自动改成“只要坚持就会赢”，也不要把残疾、疾病、死亡或照护经验当作哲理道具。需要文学性的情绪组织参照时，读取 [literary-reference.md](literary-reference.md) 中的“史铁生”条目；需要引用时，先核对可靠版本和上下文。

下面只是说明结构，不是任何作者句式或引文：

> 检查结果出来后，我把复诊日期记进手机。记下日期并不能改变结果，我也没有因此变得勇敢。只是今天能做的事里，恰好还有这一件。至于害怕，暂时留在明天。

这段话清楚地交代了结果、无法改变的部分、很小的剩余行动，以及没有被解决的害怕。它没有用“希望”覆盖无力，也没有把无力扩大成绝望。

需要查看完整的错误版本与改写版本对照时，阅读 [rewrite-examples.md](rewrite-examples.md) 的案例 3 与案例 7。两者均使用虚构教学材料，重点是“限度、动作和余波”的编辑顺序，不是可复用的个人经历。

## 情绪峰值的安排

强情绪段落可以按以下顺序推进：

`安静细节 → 事实显现 → 欲望与限度相撞 → 一句明确判断 → 剩余姿态或沉默 → 余波`

注意：

- 峰值前要有可验证的细节，峰值后要有承托它的事实或动作。
- 一篇文章通常只需要一到两个峰值；其余段落负责铺垫、转折和回声。
- 无力感的峰值往往不是喊出来，而是把“我知道不能改变”说得足够具体。
- 最后一句可以小、冷、未完成，但不能无关。它应当回扣人物正在承受的限度或仍保留的姿态。

## 文学参照

人物参照只选一到两种，先看材料再选情绪功能。参照是调音器，不是面具；不要把一篇无力感文章同时写成控诉、宣言和释怀。完整的中国文学与历史文本参照见 [literary-reference.md](literary-reference.md)。

## 交付前四问

1. 读者能否说出这段文字具体失去了什么或无法改变什么？
2. 读者能否分辨作者想要的结果和现实给出的结果？
3. 情绪有没有推动一个判断、关系变化或选择，而不是只增加音量？
4. 结尾是否允许仍有痛苦，同时让读者知道人物接下来以什么姿态存在？

答不出其中两问时，不要继续加形容词。回到事实、限度和剩余行动，或向用户索取缺失素材。
