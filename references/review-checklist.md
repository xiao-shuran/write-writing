# 审校清单

审校的目标是找出最影响成稿的缺陷，而不是把所有句子改成同一种语气。按任务类型选择相关项目，不必让一句标题接受长文级检查。

## 任务与边界

- 是否按快速、标准或深度任务选择了合适的访谈与确认强度？
- 是否已明确交付物、读者、使用场景和修订范围？
- 用户明确要求直接写时，是否说明必要假设而没有把它们写成事实？
- 用户要求润色时，是否避免越过“保守修订”的范围？
- 用户提到附件、路径、链接、样稿、媒体或资料包时，是否已核验其可读性、范围、版本和对交付的影响？

## 目的与结构

- 开头是否让目标读者知道这段文字与自己有什么关系？
- 全文是否有一个可复述的核心判断、画面、行动或情绪变化？
- 每一段是否带来新的事实、理解、关系变化或论证推进？
- 论据是否真正支持结论，是否需要说明反方、限制、例外或时间范围？
- 叙事中的事件是否改变人物处境、信息、关系或选择？
- 结尾是否完成了开头承诺，而非突然停止、重复摘要或强行升华？
- 读者是否在关键段落持续获得新的事实、判断、风险、选择或情绪回报，而不是只得到同一结论的不同说法？
- 若文章被反馈“太平”或“无聊”，是否已定位并修复期待、阻力、变化、具体性、节奏或结尾回报中的至少一项？
- 是否对照过 [reader-momentum.md](reader-momentum.md) 的相近 Before / After，确认改动改变了读者的阅读路径，而不是只增加了辞藻？
- 是否区分了“平静”和“平淡”：低调的语气是否仍有具体观察、隐含问题、认知变化或余波？
- 是否明确选择了合适的阅读体验档位？文章是否因为默认温吞而失去应有的速度、锋利度或后劲？
- 长文是否经过骨架遍、动能遍和声音遍，而不是只做了逐句抛光？
- 若有可读的 Markdown/TXT 草稿，是否需要先运行 `scripts/prose_audit.py` 获取可解释信号，并结合上下文复核，而不是把工具输出当成结论？

## 事实与材料

- 每个数字、时间、身份、因果、引号和第一人称经历是否有来源或用户授权？
- 事实、合理推断、未知内容和创作性虚构是否保持区分？
- 人物动机和情绪是否被错误写成确定事实？
- 存在材料冲突时，是否删去、条件化或明确标为待确认，而非暗自选择一个版本？
- 隐私和第三方信息是否只保留完成任务所必需的部分？
- 是否把文件名、用户摘要、无法访问路径、未提取媒体或局部节选错误地写成了“已读全文”或确认事实？
- 关键资料缺失时，是否改为框架、条件化版本或明确补问，而非编造正文、引语、数字、动机或用户声音？

## 声音与语言

- 文本是否保持用户的判断、取舍、细节和不确定性，而非变成通用“高级文案”？
- 是否存在空泛开场、机械路标、对称段落、过度形容词、礼貌性废话或假装亲历？
- 代词、主语、时态、名词和逻辑关系是否清楚？
- 句子和段落节奏是否适合目标媒介的阅读或朗读？
- 标点、数字、引号、空格、标题层级和列表格式是否一致？
- 若本次改写涉及“去 AI 味”或“加人味”，是否已用 [rewrite-examples.md](rewrite-examples.md) 的相近案例核对：新增细节是否有来源，用户声音是否被保留，抽象话是否真的落到事实或动作？

## 情绪与文学参照

- 情绪是否由事实、场景、关系、行动或限度推动，而不只是增大音量？
- 主情绪、伴随情绪和矛盾点是否被区分？是否把疲惫、无力、哀痛、绝望、麻木或认命混为一谈？
- 无力感是否具体说明了什么无法改变，并避免自动收束成励志、希望或释怀？
- 文学参照是否只改变了结构、叙述距离或收束方式，而没有变成可识别的模仿或拼贴？
- 强情绪是否保留事实承托和适当余波，而不是连续反问、感叹号或排比？
- 是否为了“抓人”虚构冲突、反转、数据、对话、人物动机或风险？若有，应删除或标为创作性虚构。
- 如果文章没有真实戏剧冲突，是否改用了认知、关系、价值、时间、处境、观察或语言动力，而不是强行加戏？

## 审稿输出

按严重程度排序，使用：

`问题：具体位置或现象。`

`影响：读者因此会怎样理解、感受或行动。`

`建议：可执行的修改方向；必要时给一小段示例。`

优先级：

- **高**：会误解主旨、破坏可信度、遗漏关键行动、造成事实风险或让结构无法成立。
- **中**：明显拖慢理解、削弱说服力、破坏场景适配或情绪推进。
- **低**：局部措辞、标点、节奏和格式问题。

审稿结束时给出一句整体判断和最值得先改的一处。用户只要审稿时，不擅自输出整篇重写稿。

## 缺失本文件时

若 `review-checklist.md` 缺失，最低检查顺序为：任务是否匹配场景 → 事实是否可确认 → 结构是否推进 → 语言是否清楚 → 修订是否越界。详见 [fallbacks.md](fallbacks.md)。

文章被评价为“太平”时，最低增加一问：每个关键段落是否改变了读者的认识、期待或人物处境？如果没有，合并、删减或补充真实阻力；不要仅替换形容词。
