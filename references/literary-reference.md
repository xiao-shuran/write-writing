# 中国文学与历史文本的情绪组织参照

本文件用于选择情绪的组织方式、叙述距离和收束方式，而不是要求模仿作者。先从用户材料确定真实情绪、场景、读者和事实边界，再只选择一到两种高层特征。古今作家不是单一情绪标签，以下内容也不是对作者本人或作品的穷尽解释。

使用近现代作者时，只提取高层特征，不复刻可识别的句式、段落、独特意象或未经核对的引文。

## 选择规则

1. 先问：这段文字想让读者看见什么事实、什么关系或什么无法改变的限度？
2. 再选：需要的是证词感、悲悯、壮志、克制、怀旧、荒诞、温厚、反讽，还是别的组织方式？
3. 最后选一到两个参照特征，落到具体的顺序、细节、句子力度或结尾，不写“用某某风格”。

当文本是工作邮件、公告、产品说明、需求文档或明确的功能性沟通时，默认不使用本文件。清楚、准确和行动指令优先于文学性。

## 古典与历史文本

| 人物或作品 | 可借鉴的情绪功能 | 写作抓手 |
|---|---|---|
| 《诗经》 | 思念、劳作中的悲喜、离别、亲密 | 让反复、物件、动作和节令承载情绪，少解释。 |
| 屈原《离骚》《九章》 | 理想受阻、忠诚、孤独、羞愤与不屈 | 让个人处境与价值判断相连，意象服务于立场。 |
| 曹操《短歌行》 | 时间焦虑、求贤、雄心与不安 | 从有限性出发，转入清楚的召唤或行动。 |
| 诸葛亮《出师表》 | 感恩、责任、忧虑、决心 | 用事实和关系做证，情绪越重，句子越直接。 |
| 王羲之《兰亭集序》 | 相聚的欣悦、盛衰无常、时间意识 | 从眼前欢乐自然转入生命有限的清醒，不突兀说教。 |
| 司马迁《报任安书》 | 受辱、疼痛、坚持、价值重估 | 不回避伤口，再说明为什么仍要完成某种使命。 |
| 陶渊明《归去来兮辞》《饮酒》 | 厌倦、退守、自在、安静决绝 | 用生活秩序与选择表达拒绝，不把决绝写成宣言。 |
| 王维部分山水诗文 | 空明、孤独、静观、距离 | 让景物承担情绪，避免把宁静写成空洞的“治愈”。 |
| 李白《行路难》《将进酒》 | 失意、自信、豪迈、愤懑、突围 | 把现实阻力和自我肯定并置；夸张必须有阻力作根。 |
| 杜甫《茅屋为秋风所破歌》等 | 个人受损、悲悯、责任、公共无力 | 从破屋、寒夜、饥饿等具体损失推向他人处境。 |
| 白居易《卖炭翁》《琵琶行》 | 同情、社会观察、迟来的理解 | 让人物自己说和做，判断从场景里浮出。 |
| 柳宗元《江雪》等 | 贬谪、孤独、冷峻自守 | 用极简场景留下空缺，不急着解释心境。 |
| 李煜《虞美人》《浪淘沙》 | 失去、囚禁、怀旧、不可逆哀痛 | 让过去的繁华与当下处境相撞，产生时间的落差。 |
| 李清照《声声慢》《金石录后序》 | 流离、丧失、记忆、孤独、清醒 | 从声音、器物、天气和生活细部进入深痛。 |
| 辛弃疾《破阵子》《丑奴儿》等 | 壮志难酬、愤懑、自嘲、公共理想 | 保留理想与个人处境的错位，不让愤怒变成空喊。 |
| 范仲淹《岳阳楼记》 | 个人得失、公共责任、愿望与自我约束 | 承认个人感受，再说明为什么仍选择更大的责任。 |

## 现代与当代中文写作

| 人物或作品 | 可借鉴的情绪功能 | 写作抓手 |
|---|---|---|
| 鲁迅《记念刘和珍君》等 | 冷峻愤怒、证词、反讽、拒绝遗忘 | 先给具体的人与事实，再让价值判断锋利。 |
| 老舍《骆驼祥子》《茶馆》 | 屈辱、耗损、体面崩塌、社会性无力 | 让环境和生计逐步改变人物，不替人物喊完。 |
| 巴金《家》等 | 青年反抗、家庭压力、内疚、理想代价 | 让情绪通过关系和行动升级，不只使用宏大口号。 |
| 曹雪芹《红楼梦》 | 温柔、欲望、嫉妒、依恋、幻灭、无常 | 同一关系保留多种真相，让细节承受暧昧。 |
| 张爱玲部分小说 | 亲密关系里的冷意、欲望、算计、失望 | 不美化动机，用精确生活细节制造关系里的刺痛。 |
| 杨绛部分散文 | 克制的哀痛、忍耐、体谅、日常尊严 | 不把悲痛喊满，让生活动作保存关系。 |
| 史铁生《我与地坛》等 | 无力、清醒、照料、限度、未完成余波 | 写清无法改变之处，再保留很小但真实的剩余行动。 |
| 汪曾祺部分散文 | 温厚、宽容、微小喜悦、日常 | 让食物、手艺、人物与地方承担温暖，不用价值口号。 |
| 王小波部分杂文与小说 | 反讽、玩心、理性距离、对庸常的抵抗 | 用幽默拉开距离，让判断藏在准确的事实和反差中。 |

## 常见组合

组合的是功能，不是表面腔调：

- **具体悲悯 + 限度意识**：先写一个可见的损失，再承认不能立刻改变什么，最后落在仍能承担的小行动。
- **证词感 + 公共责任**：先把受损事实说清，再表达不愿遗忘或不愿默认的立场。
- **怀旧 + 时间落差**：让一个旧物、旧称呼或旧习惯进入现在，显示变化本身。
- **反讽 + 克制**：不解释“荒诞”，只把不相称的细节并置，让读者看见荒诞。
- **退守 + 温厚日常**：不把离开写成失败或胜利，写人如何重新安排一日三餐、关系和时间。

## 禁止事项

- 不借文学名人替用户决定应该悲伤、愤怒、原谅或释怀。
- 不把疾病、残疾、死亡、贫困、战争或创伤写成好看的哲理道具。
- 不为了“有文采”牺牲事实准确、可读性和具体读者的理解。
- 不把不同作者的表面标志拼贴在一段里。
